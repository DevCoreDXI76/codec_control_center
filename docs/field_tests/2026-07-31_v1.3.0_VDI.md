- 문서 버전: v1.0

  다이얼/카드v2/Poly SSH) 동작 확인"을 실제로 수행하고 결과를 기록해, Phase③ DoD(M2, 목표

## 4. Phase③ DoD 판정 (PLAN.md 기준)

> "최소 1대 이상의 실제 Poly, Cisco 장비에서 상태 조회 및 기본 제어(mute 등 저위험 명령부터)가
> 정상 동작함을 확인. 보안팀 관점에서 이상 트래픽 미발생."

- [ ] Poly 실장비 ≥1대 상태조회+기본제어 정상
- [ ] Cisco 실장비 ≥1대 상태조회+기본제어 정상
- [ ] 이상 트래픽/보안 오탐 없음(C4)
- [ ] 위 3개 모두 충족 → **Phase③ DoD 충족, M2 완료 처리**
- [ ] 미충족 항목 있음 → §3 이슈 정리 후 재테스트 라운드 필요
